## Featured project

### [ParlorVP](https://parlorvp.com) — multiplayer avatar chat

Classic 90s hangout energy, modern stack:

| | |
|--|--|
| **Realtime** | WebSocket presence, chat, gestures |
| **Voice** | LiveKit SFU (Discord-style) |
| **Social** | Private rooms, Room+, Find, whispers, Party Bus |
| **Games** | Tic-Tac-Toe, Battleship, Connect Four, and more |
| **Ops** | Coolify + DigitalOcean · Cloudflare · admin dashboard |
